📦 Data Pipeline

① Authoring
Markdown src/utils/data/[BuildingID]/floor-*.md — indent 4 spaces = hierarchy, { } = metadata
② Check + Combine
npm run data:check → npm run data:combine → รวมเป็น [BuildingID]-DATA.md
③ Generate
npm run data:generate → Parse MD → JSON + TS
④ Sync to Supabase
npm run data:sync → kg_nodes + kg_edges (auto-prefix BuildingID-)
⑤ 3D Model Sync
npm run data:sync:glb → อัปโหลด GLB ไป Supabase storage
